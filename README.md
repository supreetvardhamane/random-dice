# 🎲 Dice Game (DOM Practice)

This is a small project I built to practice basic **JavaScript** and **DOM manipulation**.

It generates two random dice numbers, updates the dice images, and shows which player wins (or if it’s a draw).

## What I Practiced

* `Math.random()` for number generation
* `querySelector()`
* `setAttribute()`
* `innerHTML`
* Basic `if-else` logic

Built using **HTML, CSS, and JavaScript**.

Just a beginner project while learning JavaScript 🚀
